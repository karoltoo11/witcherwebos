# Witcher Operating System in Web

This is my custom web desktop based on The Witcher universe.
I built it using HTML, CSS and Javascript.

## Live Demo:
https://karoltoo11.github.io/witcherwebos/

## Apps & Features:
- **Bestiary**: a guide with monsters, their weaknesses and tips.
- **Contracts**: bounty board where you take contracts, answer quiz questions to hunt monsters, and earn crowns.
- **Crowns**: in-game money counter that updates when you complete contracts.
- **Notes**: simple notepad where you can write and save your notes (saved in local storage).
- **Music Player**: tavern lute audio player with songs from the game.
- **Settings**: switch witcher schools (Wolf, Cat, Bear, Viper), desktop wallpapers, and clock format.
- **Clock**: real-time working clock in the taskbar.

Made for Hack Club High Seas / WebOS.
